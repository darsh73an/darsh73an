## 🚀 Featured Projects

### 🧠 DevRank — Developer Evaluation & Recruitment Platform

A production-oriented platform that evaluates developers using evidence from
GitHub, coding platforms, resumes, projects, skills, and other legitimate
sources, while providing recruiters with explainable candidate rankings and
job-specific matching.

### ✨ Key Features

- 🔍 **Multi-Platform Developer Evaluation**
  - GitHub
  - LeetCode
  - Codeforces
  - HackerRank
  - Kaggle
  - Other supported developer platforms

- 📊 **Unified Developer Score**
  - Normalizes different technical signals into an explainable 0–100 score
  - Uses role-specific scoring criteria
  - Considers problem-solving, projects, skills, experience, coding activity,
    and technical evidence
  - Uses normalization, recency weighting, and diminishing returns

- 🛡️ **Data Trust Score**
  - Separates technical ability from data reliability
  - Distinguishes API-verified, document-supported, and self-reported data
  - Prevents unverified information from being treated as verified evidence

- 🔄 **API-First + Manual Fallback**
  - Automatically retrieves data when legitimate APIs are available
  - Provides platform-specific manual input when APIs are unavailable
  - Never fabricates missing platform data

- 🔐 **Profile Ownership Verification**
  - Supports profile verification where technically possible
  - Tracks verification method and verification status
  - Helps recruiters distinguish an actual candidate-owned profile from an
    unverified public profile

- ⚠️ **Data Conflict Detection**
  - Detects differences between candidate-provided and externally verified
    information
  - Preserves both values instead of silently overwriting data

- 🕒 **Data Freshness**
  - Tracks when platform information was retrieved and verified
  - Identifies stale information
  - Allows recruiters to trigger re-verification

- 📄 **Resume Intelligence**
  - Extracts skills, education, experience, projects, certifications, and
    other relevant information from resumes
  - Provides role relevance and skill-gap analysis

- 🤖 **AI-Powered Insights**
  - Generates evidence-based candidate summaries
  - Identifies strengths and skill gaps
  - Provides personalized improvement recommendations
  - Explains job matches
  - AI never invents candidate achievements or statistics

- 📈 **Candidate Growth Tracking**
  - Stores historical evaluations instead of overwriting previous scores
  - Tracks developer-score progression over time
  - Shows improvements across skills and technical areas

- 👨‍💼 **Recruiter Dashboard**
  - Candidate search and filtering
  - Candidate ranking
  - Candidate comparison
  - Verification status
  - Evidence inspection
  - Recruiter notes
  - Shortlisting
  - Hiring pipeline
  - Job-specific candidate matching

- 💼 **Job-Specific Matching**
  - Recruiters can create job requirements
  - Matches candidates against required and preferred skills
  - Generates a job-match percentage
  - Explains why a candidate matches a specific role

- ⚖️ **Evidence-Based Evaluation**
  - Every major score is backed by identifiable evidence
  - Clearly distinguishes verified and self-reported information
  - AI recommendations are advisory rather than automated hiring decisions
